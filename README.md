# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date:

## AIM
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE

Step 1: Preparing the sheet and reference lines

    1.  Fix the drawing sheet firmly onto the drawing board using clips or drafting tape.
	
	2.  Draw a suitable border line and make a title block at the bottom right corner. 
	
	3.  Use the arrow marked "FRONT" to decide the layout orientation:
	
	    •  The Front View (FV) is drawn looking from the direction of the arrow.
        •  The Top View (TV) is projected directly below the Front View. 
	    •  The Side View (SV), which is the Right Side View, is projected to the left or right of the 
	      Front View depending on the First/Third Angle Projection convention (First Angle is standard unless specified otherwise).

  <img width="907" height="597" alt="image" src="https://github.com/user-attachments/assets/9263e8fa-d431-4c9a-a48c-f448bdea8b16" />

 Step 2: Drawing the Front View (FV) 
		  
		  1.  Project or measure the overall base width of 100 mm horizontally and a total height of
		     50 mm vertically for the main body.
		  2.  Draw the outline of the main rectangular body. 
		  3.  Locate the central cylindrical lens (Ø50) on the front face:
		      •  Centre it horizontally across the 100 mm width.
			  •  Draw the circular lens outline with a diameter of 50 mm.
	      4.  Add the top attachments that are visible from the front: 
			  •  Draw the profile of the central trapezoidal flash/viewfinder block, showing the 45° slope.
			  •  Draw the outlines of the smaller top buttons/dials on the upper surface. 
		  5.  Darken the visible outlines using an HB pencil.

  <img width="785" height="522" alt="image" src="https://github.com/user-attachments/assets/1dd66cdb-149b-465f-a242-16c2b7f17db1" />

  Step 3: Drawing the Top View (TV) and Side View (SV)
  
  Top View 
    
	    1.  Project vertical lines downwards from all the major features of the
		     Front View so the width lines up cleanly.
		2.  Mark the total depth of the object, which is 35 mm for the main body
		   plus the 20 mm lens projection (the total depth extends to 55 mm). 
		3.  Draw the rectangular top profile of the camera body (100 mm width × 35 mm depth). 
		4.  Show the cylindrical lens projecting forward by drawing its circular profile or 
		    projection boundaries for the depth of 20 mm.
		5.  Draw the top square button block and the circular dial (Ø20) on the top surface, 
		     using the given offset dimensions (e.g., 15 mm spacing references).
		
		
 Side View 
		
		1.  Using a 45° miter line from the top-view projection boundaries, or
		    direct horizontal projections from the Front View, construct the Side View.
		2.  Draw the overall depth box (width/depth of 35 mm) and the height 
		  (50 mm base plus the top components).
		3.  Outline the profile of the camera body from the side, showing how
		   the lens protrudes forward by 20 mm and how the top attachments sit on the upper tier.

Step 4: Dimensioning and final finishing 

  1.  Dimension all the crucial features clearly using thin lines, extension lines and arrowheads
      (e.g., overall length 100, height 50, depth 35, lens diameter Ø50, lens projection 20, dial diameter Ø20
  2.  Make sure any hidden details (if there are internal cavities) are shown with dashed/dotted lines,
  3.  though most of the visible features here are external. 3.  Clean up any extra construction lines
  4.  check the dimension accuracy against the reference drawing, and darken the final object lines.
